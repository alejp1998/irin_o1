📖 About this page

🎓 The Project

IRIN O1 — Trabajo Obligatorio 1 (UPM, 2019): an e-puck robot in the Webots simulator navigates a 20×20 grid arena using a subsumption architecture (wandering, obstacle avoidance, goal-seeking, recharging) with an A* path planner on top. The controller (iri1controller.cpp) builds a map of explored cells from its ground-memory sensor and plans routes with A*.

🧮 The algorithm

This page runs the controller's exact pathFind() port: 8 directions with a straight-line bias (straight moves cost 0, diagonals cost 2), priority level + estimate×10, and the route encoded as direction indices. Amber = open set, blue = closed set, green = the final route.

🖱️ How to use

Left-click to place the start, shift-click to place the goal, right-click/drag to paint walls (or load the O1 arena preset), then ▶ Run A* and watch the search expand. The speed slider animates the exploration step by step.

🖥️ Implementation

The C++ pathFind() was ported 1:1 to Python (astar.py, 8 unit tests) and JavaScript for this page. Source: github.com/alejp1998/irin_o1.
